# Week 7 – Next Token Probability Analysis Using GPT-2

## Project Overview

This project uses the GPT-2 language model to analyze the probability of the next token for a given text prompt.

The program loads GPT-2 using the Hugging Face Transformers library, processes multiple prompts, calculates the probability distribution for the next token, and displays the Top 5 most probable next-token candidates.

The results are also saved into a CSV file for further analysis.

## Objectives

- Load a small open-source language model.
- Tokenize input text using a GPT-2 tokenizer.
- Obtain model logits for the next token.
- Convert logits into probabilities using Softmax.
- Identify the Top 5 next-token candidates.
- Display their token IDs and probabilities.
- Save the results into a CSV file.

## How the Program Works

### Step 1: Load the Model
The GPT-2 tokenizer and model are loaded using Transformers.

### Step 2: Tokenize the Prompt
Each prompt is converted into token IDs.

### Step 3: Generate Logits
The model produces logits representing scores for possible next tokens.

### Step 4: Convert Logits to Probabilities
Softmax is applied to convert logits into probability values.

### Step 5: Select Top 5 Tokens
The program identifies the five tokens with the highest probabilities.

### Step 6: Display Results
The program displays:
- Rank
- Token
- Token ID
- Probability

### Step 7: Save Results
The results are saved into:

```text
week7_probability_results.csv
```

## Key Concepts

### Tokenization
Converts text into smaller units called tokens that the language model can process.

### Logits
Raw scores generated by the language model for possible next tokens.

### Softmax
Converts logits into probability values.

### Top-K
Selects the K most probable candidates. In this project:

```text
K = 5
```

### Next-Token Prediction
The model predicts which token is most likely to appear after the given prompt.

## Conclusion

This project demonstrates how a GPT-2 language model can be used to inspect next-token probabilities. It provides an understanding of tokenization, logits, probability distributions, and Top-K prediction using Python, PyTorch, and Hugging Face Transformers.
